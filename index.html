Selamat datang

Lihat sebaran kasus TBC di Bantul dalam sekejap

Unggah file register TBC apa adanya, tanpa perlu dirapikan atau diubah formatnya. Dashboard akan membaca sendiri kolom-kolomnya, lalu menampilkan peta per kecamatan, tren kasus, dan grafik pendukung lainnya.

  1. Siapkan file. Gunakan register TBC hasil tarikan dari SITB, dalam bentuk Excel (.xlsx) atau CSV.
  2. Klik Unggah data. Cek pasangan kolomnya. Biasanya sudah terisi otomatis, tinggal dipastikan.
  3. Lihat hasilnya. Peta dan grafik langsung muncul, dan bisa difilter per tahun maupun bulan.

Data pasien tetap aman: file hanya diproses di browser ini dan tidak dikirim ke server mana pun. Nama, NIK, dan alamat pasien tidak disimpan. Mau membandingkan antar tahun? Unggah file tiap tahun satu per satu.

Data penyakit ini sangat sensitif. Angka kecil per kecamatan (kurang dari 3) ditampilkan sebagai "<3" karena berisiko mengungkap identitas. Warna peta dan batang grafik tetap menggambarkan angka sebenarnya, jadi jangan ditayangkan atau dibagikan ke pihak yang tidak berwenang.
